 BACKEND API (14 Endpoints)
═════════════════════════════════════════════════════════════════════════════

✅ User Endpoints
   GET  /api/users              → List all users
   GET  /api/users/current      → Get current user

✅ Expense Endpoints
   GET  /api/expenses           → List expenses
   POST /api/expenses           → Add expense
   DELETE /api/expenses/{id}    → Delete expense
   PUT  /api/expenses/{id}      → Update expense

✅ Income Endpoints
   GET  /api/income             → List income
   POST /api/income             → Add income
   DELETE /api/income/{id}      → Delete income

✅ Budget Endpoints
   GET  /api/budgets/{user_id}  → Get budget
   PUT  /api/budgets/{user_id}  → Update budget

✅ Statistics Endpoints
   GET  /api/stats/{user_id}    → Dashboard stats

✅ Health Endpoints
   GET  /api/health             → Server status

 DATABASE SCHEMA (4 Tables)
═════════════════════════════════════════════════════════════════════════════

📊 users
   ├─ id (Primary Key)
   ├─ name (VARCHAR 100)
   ├─ email (VARCHAR 255, UNIQUE)
   ├─ password (VARCHAR 255, bcrypt)
   ├─ created_at (DATETIME)
   └─ updated_at (DATETIME)

💸 expenses
   ├─ id (Primary Key)
   ├─ user_id (Foreign Key → users.id)
   ├─ title (VARCHAR 255)
   ├─ category (ENUM: 8 types)
   ├─ amount (DECIMAL 12,2)
   ├─ payment_method (ENUM: 4 methods)
   ├─ notes (TEXT)
   ├─ date (DATE)
   ├─ created_at (DATETIME)
   ├─ updated_at (DATETIME)
   └─ Indexes: (user_id, date), (user_id, category)

💰 income
   ├─ id (Primary Key)
   ├─ user_id (Foreign Key → users.id)
   ├─ source (VARCHAR 150)
   ├─ amount (DECIMAL 12,2)
   ├─ date (DATE)
   ├─ notes (TEXT)
   ├─ created_at (DATETIME)
   └─ Index: (user_id, date)

📈 budgets
   ├─ id (Primary Key)
   ├─ user_id (Foreign Key → users.id, UNIQUE)
   ├─ monthly_budget (DECIMAL 12,2)
   ├─ daily_limit (DECIMAL 12,2)
   ├─ warn_threshold (TINYINT 1-100)
   └─ updated_at (DATETIME)
